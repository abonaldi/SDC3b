Inferring the reionization history from simulated SKA-Low data

Teams in the SKA Data Challenge 3b inferred the volume-averaged neutral hydrogen fraction xHI in three frequency bands (151–166, 166–181 and 181–196 MHz) from simulated 21-cm power spectra (PS1–PS3) and an image cube (IM1). Each submission is a 3-D posterior grid P(x1, x2, x3). This site lets you compare the submitted posteriors with the true input values.

The aim is to learn where and why the inferences differ from the input, so that methods and future challenges can be improved. The results are not a ranking of teams: no single number captures the quality of a posterior, and the challenge setup itself has limitations discussed in the paper.

    Select one or more teams to plot their posteriors.

    Diagonal: 1-D marginal posteriors, scaled to unit peak. Off-diagonal: 2-D marginals with highest-density credible regions. Dashed lines and stars mark the true xHI at the band centres; the grey shading spans the true xHI over each band. Use the camera icon to save the figure.

    Boxes show the 68% and whiskers the 95% equal-tailed credible intervals of the 1-D marginals; markers are the marginal medians. The dashed line is the true band-centre value and the shaded area the true range over the band.

    Teams are listed in the same order as in the paper.

    These quantities are diagnostics, each describing one aspect of how a posterior relates to the input values (offset, width, shape). They are meant to help understand the results, not to rank the teams.

    Zp
    |mean − true value| / σ of the marginal posterior in band p: the offset from the input in units of the posterior width.
    DM
    Mahalanobis distance of the true values from the posterior mean, using the full 3×3 posterior covariance.
    SSDC3b
    Fraction of the posterior mass inside the cuboid spanned by the true xHI range of each band, as defined for the challenge.

    Download the posteriors

    The posterior grids are attached to the GitHub release of the SDC3b repository, one zip file per dataset:

      Or fetch and unpack all of them with

      git clone https://github.com/abonaldi/SDC3b.git
cd SDC3b
pip install -r analysis/requirements.txt
python analysis/scripts/fetch_posteriors.py

      File format

      Each file <team>_<dataset>.fits holds a 100×100×100 grid of the posterior probability over (x1, x2, x3), with cell centres at xHI = 0.005, 0.015, …, 0.995. When read with astropy, numpy axis 0 is x1 (151–166 MHz). All grids are normalised to unit sum; submissions that were not normalised have been normalised. 

      import sys; sys.path.insert(0, 'analysis')
import sdc3b_tools as st

posteriors, coords = st.load_case('PS1')   # [(team, grid), ...], cell centres
truth = st.load_truth('PS1')               # band-centre values and ranges
